# Portfólio Power BI

Repositório de estudos e projetos práticos com Power BI. Os arquivos demonstram um fluxo de trabalho que vai da obtenção e preparação dos dados à modelagem, criação de medidas e construção de relatórios para diferentes cenários.

## Competências demonstradas

- **Preparação de dados:** importação, limpeza, transformação, tratamento de dados inconsistentes e desnormalização.
- **Integração de fontes:** combinação e mesclagem de tabelas e arquivos, com fontes CSV, Excel, texto e web.
- **Modelagem:** relacionamentos, tabelas de calendário e organização de dados para análise.
- **DAX:** criação de medidas, lógica condicional, filtros, rankings e cálculos de inteligência temporal.
- **Visualização e análise:** dashboards, gráficos e exploração de dados de vendas, orçamento, indicadores econômicos e conjuntos de dados analíticos.

## Outros estudos

Os demais arquivos ampliam a prática com limpeza de dados, importação de dados da web, ranking, bases lógicas e conexão a arquivos em SharePoint, Google Drive e OneDrive. Os nomes dos arquivos indicam o tema de cada exercício.

As fontes usadas nos exercícios estão organizadas em [`Fontes/`](Fontes/), incluindo bases de pessoas, estrutura, vendas, produtos e orçamento.

## Como explorar

1. Abra um arquivo `.pbix` no Power BI Desktop.
2. Consulte a pasta `Fontes/` se o relatório solicitar a localização dos dados de origem.
3. Explore as consultas, o modelo, as medidas e as páginas do relatório para acompanhar cada etapa.

> Os arquivos são projetos de estudo e portfólio. A disponibilidade de conexões externas pode depender de credenciais ou configurações locais.
